FTC Coaching Roadmap

This page gives coaches a shared structure for FTC classes: mechanical systems, Java programming, CAD, controls, testing, judging, and competition readiness.

FTC Fall/Summer adaptable Coach-only

Phase 1: Foundations

Weeks 1-2

  • FTC kit, control system, safety, tools, and team roles
  • Drivetrain basics, build quality, wiring habits, and inspection mindset
  • Java project setup, OpModes, gamepad input, motors, and servos

Phase 2: Mechanisms

Weeks 3-4

  • Intakes, lifts, arms, linkages, and end effectors
  • Gear ratios, torque/speed tradeoffs, and iteration logs
  • CAD sketches and mechanism review before major rebuilds

Phase 3: Controls

Weeks 5-6

  • Driver controls, field-centric driving, sensors, and telemetry
  • Autonomous path planning, encoders, IMU, and repeatability testing
  • Debugging routines and match-ready code organization

Phase 4: Strategy

Weeks 7-8

  • Game analysis, scoring priorities, cycle time, and match roles
  • Driver practice, failure drills, pit checklist, and repairs
  • Engineering portfolio evidence and judging talking points

Phase 5: Competition Readiness

Ongoing

  • Scrimmages, timed runs, autonomous reliability, and scouting
  • Inspection prep, battery management, tools, spares, and code backups
  • Post-match review and next-practice action items

Coach Checklist

  • Create FTC classes in the Master Roster and enroll students.
  • Keep a weekly build/programming goal, one measurable test, and one reflection artifact.
  • Capture photos of mechanisms, wiring, CAD, test results, and code milestones for judging.
