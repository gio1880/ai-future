# Design Demos

This folder stores archived landing-page animation prototypes and scroll experiments.

These files are kept only as visual/design references. They are not production pages,
should not be linked from the live site, and should not be indexed by search engines.

Current files:

- `program-scroll-animation-demo.html` - early program-card scroll animation concept.
- `program-scroll-cinematic-demo.html` - cinematic program scroll prototype.
- `program-scroll-cinematic-reference.html` - preserved reference copy of the cinematic prototype.
- `program-scroll-frame-scrub-demo.html` - frame-scrub style scroll experiment.
- `program-scroll-mascot-demo.html` - mascot-focused scroll concept.
- `program-scroll-pathway-demo.html` - pathway/timeline scroll concept.
- `program-scroll-video-bg-demo.html` - video-background scroll concept.
- `robotics-courses-scroll-demo.html` - robotics course pathway scroll animation concept.
