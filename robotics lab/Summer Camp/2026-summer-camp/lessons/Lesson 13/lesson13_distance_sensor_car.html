Car with Distance Sensor

Quick Review

From Simple Car to Smart Car

Chassis

A square frame keeps the rover sturdy.

Parallel axles help the car roll straight.

Now Add Input

A distance sensor gives the robot information about what is ahead.

Today's Goal

Lesson Goal

Today I will build a distance sensor car that uses a sensor reading to stop, back up, or turn before hitting an object.

Concept

Input, Threshold, Response

Input

The sensor measures how far away an object is.

Threshold

The program checks if the distance is smaller than a chosen number.

Response

The rover changes motion when the condition is true.

LEGO Building Tips

Technic Tips: Distance Sensors

Face Forward

Mount the sensor straight so it looks at the obstacle, not the floor.

Protect the Sensor

Add a bumper nearby, but do not block the sensor window.

Clear the Wires

Keep cables above the wheels and away from the axle path.

Builder advice: Test the sensor by hand before running the rover at full speed.
Build Check

Can the Rover See?

Secure Mount

The sensor should not wobble during driving.

Clear View

No beams, bumpers, or wires should cover the sensor.

Straight Roll

The car should still roll straight after the sensor is added.

BioGlow Mission

BioGlow Mission: Stop Before Impact

The BioGlow rover must approach glowing habitat walls and supply crates without crashing. Engineers need a distance sensor system that reacts before contact.

Mission prompt: What distance gives your rover enough time to respond safely?
Challenge

Challenge Rules: Obstacle Response

1Build a car with a forward-facing distance sensor.
2Start behind the same line each trial.
3Drive toward a wall or box obstacle.
4Stop, back up, or turn when the obstacle is detected.
5Do not crash into the obstacle.
6Record the response distance and result.
Fair Testing

Keep the Test Fair

Same Obstacle

Use the same box or wall for every trial.

Same Start

Begin from the same line and direction.

Same Speed

Change one setting at a time, not everything at once.

Improve

Improve the Detection

Try Changing

  • Sensor height
  • Distance threshold
  • Driving speed
  • Bumper position

Watch For

  • False readings
  • Stopping too late
  • Turning before the obstacle
  • Loose sensor mounts
Reflection

After Testing: Reflection

1. What distance worked best for your rover?
2. What caused missed or false readings?
3. How did speed affect stopping accuracy?
4. What would you change before adding steering?
