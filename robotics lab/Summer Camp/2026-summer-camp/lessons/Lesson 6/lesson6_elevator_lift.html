Today's Goal

Lesson Goal

Today I will build a stable lift that raises a small load using vertical motion, guides, load balance, and low friction.

Concept

What Makes a Lift Work?

Structure

A tall frame must stay rigid while the load moves.

Guides

Rails or beams keep the platform from tipping.

Pulling System

A string, gear, pulley, or crank can move the load upward.

LEGO Building Tips

Technic Tips: Elevators and Lifts

Brace the Tower

Add cross beams or triangle supports so the frame does not twist.

Guide Both Sides

Use two rails when possible so the platform rises straight instead of tilting.

Check Clearances

Leave a small gap so the platform can move without scraping the tower.

Builder advice: Test with an empty platform first, then add the load after the motion is smooth.
Build Check

Smooth and Stable

No Jamming

The platform should move without catching.

Balanced Load

Keep the crate centered so the lift does not tilt.

Strong Base

A wide base stops the tower from tipping.

BioGlow Mission

BioGlow Mission: Raise the Supply Crate

The BioGlow habitat needs supplies lifted to an upper lab platform. Engineers must build a lift that raises a crate smoothly without tipping, dropping, or jamming.

Mission prompt: How can your lift move the crate higher while keeping the tower stable?
Challenge

Challenge Rules: Working Lift

1Build a tower and moving platform.
2Raise one small classroom load.
3The load must stay on the platform.
4Measure the highest safe lift height.
5Do not hold the tower while testing.
6Stop if the structure begins to fall.
Fair Testing

Keep the Test Fair

Same Load

Use the same object for every team.

Same Start

Begin with the platform at the bottom.

Same Measure

Measure from floor to platform height.

Improve

Improve Your Lift

Try Changing

  • Base width
  • Platform guides
  • Crank or pulling point
  • Load position

Watch For

  • Tilting
  • Jamming
  • String slipping
  • Tower twisting
Reflection

After Testing: Reflection

1. What made your lift stable?
2. What made it move smoothly?
3. What limited how much weight or height it could handle?
4. What would you improve next?
