Today's Goal

Lesson Goal

Today I will guide a marble using gravity, slope, turns, barriers, and iteration so it completes a path reliably.

Concept

How Does the Marble Move?

Potential Energy

A higher start gives the marble energy to move.

Slope

Steeper tracks make the marble speed up.

Control

Barriers, curves, and supports keep it on the path.

LEGO Building Tips

Technic Tips: Marble Runs

Support Every Ramp

Long beams need posts or braces so the track does not sag.

Build Guardrails

Add beams along turns and steep drops to keep the marble on the path.

Control the Speed

Use gentler slopes before turns so the marble does not fly off.

Builder advice: Test one section at a time before connecting the whole run.
Build Check

Reliable Before Fancy

Supported Track

Every ramp needs enough support to stay in place.

Safe Turns

Turns need walls or guards so the marble stays on.

Catch Zone

The marble should finish in a clear stopping area.

BioGlow Mission

BioGlow Mission: Move the Glow Samples

The BioGlow lab needs glowing sample spheres moved safely from one station to another. Engineers must design a marble run that controls speed, prevents spills, and finishes reliably.

Mission prompt: How can your team slow the sample down just enough to keep it on track?
Challenge

Challenge Rules: Reliable Marble Run

1Build a start, path, and finish zone.
2The marble must move by gravity only.
3No pushing after release.
4The marble must stay on the track.
5Each team gets 3 official trials.
6Record successful finishes and failure points.
Fair Testing

Keep the Test Fair

Same Marble

Use the same ball or marble for each trial.

Same Start

Release from the same start point.

Same Goal

Define the finish zone before testing.

Improve

Improve Your Marble Run

Try Changing

  • Ramp height
  • Slope angle
  • Turn shape
  • Wall or barrier placement

Watch For

  • Too fast
  • Too slow
  • Track sagging
  • Marble leaving the path
Reflection

After Testing: Reflection

1. Where did the marble speed up or slow down?
2. Where did it fall off or get stuck?
3. What change made the run more reliable?
4. What would you add with more build time?

Quick Lesson Flow

Before Building

  • Review controlled motion.
  • Introduce gravity and slope.
  • Show support and barrier ideas.
  • Explain reliability testing.

During / After Building

  • Build path and finish zone.
  • Run 3 official trials.
  • Fix the biggest failure point.
  • Retest after one change.
  • Reflect on speed, control, and reliability.
