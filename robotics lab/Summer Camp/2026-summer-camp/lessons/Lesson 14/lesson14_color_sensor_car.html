Concept

How Color Detection Works

Color

The sensor identifies a color or reflected light value.

Height

The sensor works best when it is close to the floor.

Calibration

Lighting and surface color can change readings.

LEGO Building Tips

Technic Tips: Color Sensors

Close, Not Dragging

Place the sensor near the floor with a small gap.

Stay Centered

Put the sensor where it passes over the color marker.

Use Clear Markers

Large, bright markers are easier to read reliably.

Builder advice: Test each color before the full run; classroom lighting matters.
Build Check

Can the Rover Read the Path?

No Dragging

The sensor should not scrape the floor.

Reliable Read

Test each color at least three times.

Stable Motion

The car should pass smoothly over the marker.

Challenge

Challenge Rules: Color Response

1Build a car with a downward-facing color sensor.
2Place color markers on the test path.
3Start behind the same line.
4Program at least two different color responses.
5The rover must react when it reaches the marker.
6Record correct reads and missed reads.
Fair Testing

Keep the Test Fair

Same Lighting

Test in the same part of the room.

Same Markers

Use the same color cards each trial.

Same Height

Do not change sensor height unless that is the one variable.

Improve

Improve the Color Read

Try Changing

  • Sensor height
  • Marker size
  • Car speed
  • Program condition

Watch For

  • Light glare
  • Sensor dragging
  • Markers too small
  • Colors that read similarly
Reflection

After Testing: Reflection

3. How did sensor height affect the reading?
4. How could color sensing help a final robot?
