Find the Right Robotics Path

Each program builds technical skill, confidence, and a clear next step for your child.

Grades K-5

LEGO SPIKE Robotics

A friendly first robotics pathway for younger builders. Students learn how sensors, motors, simple machines, and code work together through hands-on builds.

Beginner FriendlyLEGO SPIKE EssentialLEGO SPIKE Prime
  • Build confidence with guided robot builds and creative challenges.
  • Learn sequencing, loops, sensors, motors, and basic problem solving.
  • Prepare for future FLL-style teamwork, presentations, and project thinking.
Ask About LEGO SPIKE
Grades 4-8

FIRST LEGO League (FLL)

FLL blends robot design, coding, research, teamwork, and live competition. Students learn to solve missions on a field while developing an innovation project around a real-world theme.

Competition TrackRobot DesignInnovation Project
  • Design attachments and strategies for autonomous mission runs.
  • Program reliable robot movement using sensors and iterative testing.
  • Build presentation, judging, teamwork, and engineering notebook habits.
Ask About FLL
Grades 4-8

VEX IQ

VEX IQ is a strong next step for students ready for more advanced mechanisms, driver strategy, autonomous programming, and fast-paced competition challenges.

Intermediate BuildDriver SkillsAutonomous Skills
  • Learn drivetrain design, lifts, intakes, gear ratios, and structural strength.
  • Practice team strategy, match play, and competition troubleshooting.
  • Develop stronger coding foundations for autonomous robot behavior.
Ask About VEX IQ
Grades 7-12

FIRST Tech Challenge (FTC)

FTC gives older students a real engineering-team experience: metal-frame robots, Java programming, CAD, controls, strategy, outreach, judging, and competition execution.

Advanced CompetitionJavaCAD & Engineering
  • Build and iterate competition robots with mechanical and electrical systems.
  • Program autonomous and tele-op robot behavior using Java-based controls.
  • Practice engineering portfolio, outreach, judging, and leadership roles.
Ask About FTC
Grades 9-12

VEX V5

VEX V5 is built for advanced students who want high-performance robot design, rigorous iteration, complex mechanisms, and strategic competition preparation.

Advanced EngineeringHigh SchoolCompetition Strategy
  • Design robust high-speed mechanisms and competition-ready drivetrains.
  • Strengthen coding, control systems, debugging, and match strategy.
  • Prepare for leadership, build documentation, and high-level robot iteration.
Ask About VEX V5
