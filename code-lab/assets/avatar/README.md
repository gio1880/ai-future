# GritBot Avatar Assets

This folder is reserved for future avatar art files if the shop moves beyond
inline CSS/SVG layers.

Planned subfolders:

- `base/` - GritBot base body layers
- `eyes/` - eyes, visors, goggles, glasses
- `hats/` - caps, helmets, crowns, headphones
- `backpacks/` - battery packs, bags, jetpacks, toolkits
- `badges/` - achievement chest badges
- `effects/` - trails, glow, sparks, celebration effects
- `backgrounds/` - avatar scene backgrounds

The current MVP renders avatar parts with CSS and inline HTML in
`code-lab/index.html` so students can mix many items without loading a large
image set.
