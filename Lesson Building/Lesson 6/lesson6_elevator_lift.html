Today's Goal

Lesson Goal

Today I will build a windmill and write my first SPIKE Prime program to control one motor — starting it, setting its speed, changing its direction, and stopping it.

Meet SPIKE Prime

The Hub + a Motor

The Hub = the brain 🧠

It runs your program and sends power to the motor.

The Motor = the muscle 💪

Plug it into a port labeled A–F. Today we use one motor to spin the windmill.

Show students: point out the Hub ports and how the motor cable clicks into port A.
What is a program?

Instructions, in order

A program is a list of steps the Hub follows from top to bottom — just like a recipe.

▶ when program starts A start motor wait 3 seconds A stop motor
Motor blocks

Control ONE Motor

A start motor A stop motor

Start & Stop

Turn the motor on, then off.

A set speed to 50% A run for 2 rotations

Speed & Amount

How fast, and how far it turns.

Direction: a positive speed spins one way (clockwise); a negative speed spins the other way (counter‑clockwise).
Build Brief

Build the Windmill

1 · Motor + axle

Put an axle into the motor so it turns when the motor spins.

2 · Balanced blades

Add 3–4 blades the same size, evenly spaced around the axle.

3 · Steady stand

Build a base that holds the motor still while the blades spin.

Program Brief

Make It Spin — Step by Step

▶ when program starts A set speed to 50% A start motor wait 3 seconds A stop motor
Then experiment: raise the speed to 100%, or use a negative speed to spin the other way. Change ONE thing at a time.

Build Check

Spins Smoothly?

Free to Spin

The axle turns without rubbing the stand.

Balanced Blades

Even blades stop the windmill from wobbling.

Motor Secure

The motor stays put while the blades spin.

Predict & Test

Question

If you change the motor speed from 50% to 100%, what will happen to the windmill?
Try it! Then try a negative speed and watch the direction change.
Reflection

After Testing: Reflection

1. Which block turned the motor on? Which one stopped it?
2. What did a higher speed % change?
3. How did you make the blades spin without wobbling?
4. What would you program your motor to do next?

Quick Lesson Flow

Before Building

  • Review Week 2 builds; introduce the Hub + motor.
  • Explain "a program = steps in order".
  • Show start / stop / set speed / direction blocks.

During / After Building

  • Build a balanced windmill on one motor.
  • Run the first program (set speed → start → wait → stop).
  • Experiment: change speed, reverse direction.
  • Reflect on motor control + balance.
