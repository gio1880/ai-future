Concept

How Does a Gripper Work?

Pivot

A pivot lets each jaw rotate open and closed.

Linkage

Connected beams transfer motion from your hand to the jaws.

Friction

Grip surfaces help hold objects without crushing them.

LEGO Building Tips

Technic Tips: Grippers

Mirror the Jaws

Build left and right sides the same so they close evenly.

Do Not Over-Tighten

Pins should hold parts together while still allowing movement.

Add Grip

Use tires, rubber pieces, or textured parts when the object slips.

Builder advice: If one jaw moves more than the other, compare the linkage holes on both sides.
Build Check

Open, Close, Hold

Open Wide

The jaws need enough space to fit around the object.

Close Evenly

Both sides should touch the object at about the same time.

Release Cleanly

The object should let go when the jaws open.

Challenge

Challenge Rules: Pick, Hold, Release

1Build a gripper with moving jaws.
2Pick up the test object from the table.
3Hold it for 5 seconds.
4Move it to the target zone.
5Release without touching the object by hand.
6Record success, drops, and slips.
Fair Testing

Keep the Test Fair

Same Object

All teams test with the same item.

Same Start

Place the object in the same start zone.

Same Hold Time

Use the same 5-second hold test.

Improve

Improve Your Gripper

Try Changing

  • Jaw length
  • Pivot location
  • Grip surface
  • Linkage holes

Watch For

  • Object slipping
  • Jaws closing unevenly
  • Too much force
  • Parts binding at pivots
Reflection

After Testing: Reflection

1. What helped your gripper hold the object?
2. What made the object slip or fall?
3. How did pivot location change jaw movement?
4. What would you change for a smaller or larger object?
