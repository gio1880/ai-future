New Idea

What Is an Event?

An event is something that happens — a button press, a tap, a sensor seeing something. Event blocks say: WHEN this happens → DO that.

Doorbell

WHEN pressed → DO ring.

Game controller

WHEN you press A → DO jump.

Your claw

WHEN button pressed → DO close the claw.

Event blocks

"When" Blocks Are Hats 🎩

Event blocks sit on TOP of a stack — the steps under them only run when the event happens.

▶ when program starts the classic — runs once at the start
🕹️ when left button pressed runs EVERY time you press it
Key idea: a program can have MORE than one stack — each event block starts its own stack, waiting for its moment.
Program Brief

Button Controls the Claw

Close

🕹️ when left button pressed A run for 1 rotations

Open

🕹️ when right button pressed A run for −1 rotations
Tune it: if the claw closes too far or not enough, change the rotations (try 0.5). The negative number runs the motor the OTHER way — that's what opens it.

Challenge

Challenge: Pick It Up With Buttons Only

1Press a button to close the claw on the object.
2Lift or move it to the target zone.
3Press the other button to release it.
4No touching the object with your hands!
53 tries — count your clean pickups.
6Bonus: make the Hub beep or light up on each press.

Reflection

After Testing: Reflection

1. What event did your program wait for?
2. Why do we need TWO event stacks for the claw?
3. How many rotations worked best for a clean grip?
4. What other event would be cool to use? (tilt? shake? sensor?)
